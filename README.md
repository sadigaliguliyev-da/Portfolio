// 04 — HAQQIMDA
Kim Mənəm?
❝
HEKAYƏM
Mənim data ilə tanışlığım sadə bir sualdan başladı: "Bu rəqəmlər nə deməkdir?" — Azərbaycan Universitetinin Kompüter Mühəndisliyi proqramında oxuyarkən fərq etdim ki, texnologiya yalnız kod yazmaq deyil, məlumatları düzgün oxumaq, onlara sual vermək və cavab tapmaq bacarığıdır. Bu anlayış məni data analitikaya yönəltdi. Code Academy-nin intensiv data analitika proqramını uğurla başa vurdum, Google-un AI Essentials və Meta-nın Data Analytics sertifikatlarını qazandım. Bu sertifikatlar yalnız sənəd deyil — hər birinin arxasında onlarca saatlik praktiki iş, real dataset-lər üzərindəki analizlər və həll etdiyim problemlər dayanır. Excel-dən MySQL-ə, R proqramlaşdırma dilindən statistik modelləşdirməyə qədər hər alət mənim üçün bir dil — məlumatların dilini danışmağı öyrənmək üçün vasitə.
🎯
NIYƏ MƏN?
Gənc olmaq bir çox şey deməkdir — öyrənmə sürəti yüksəkdir, yeni texnologiyalara adaptasiya sürətlidir, ən əsası isə hər problemə təzə gözlə baxmaq mümkündür. Mən yalnız alətləri bilən biri deyiləm; həm də onları niyə istifadə etdiyimi anlayan biriyəm. Data cleaning-dən data manipulation-a qədər hər addımda məqsədim eynidir: səs-küydən siqnalı ayırmaq, mürəkkəblikdən aydınlıq yaratmaq. Komanda ilə işləməyi, suallar verməyi və cavabların yalnız cədvəldə deyil, real həyatda fərq yaratdığını görmə həvəsini özümdə daşıyıram. Hər yeni layihə mənim üçün yalnız tapşırıq deyil — öyrənmə imkanıdır. Əgər datanı birgə mənalı bir şeyə çevirmək istəyirsinizsə, əlaqə saxlayın — hazıram.
